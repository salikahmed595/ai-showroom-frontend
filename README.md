## 🌟 Overview

The **AI Showroom Frontend** is a dynamic, responsive web interface designed to showcase AI products and automation tools. It connects seamlessly to the [AI Showroom Backend](https://github.com/salikahmed595/ai-showroom-backend) to deliver real-time product listings, AI-powered recommendations, and interactive demos.

Whether you're an AI enthusiast, investor, or potential client — this platform gives you a premium visual experience of the latest AI innovations.

---

## ✨ Features

- 🎨 **Modern UI/UX** — Clean, responsive design optimized for all devices
- ⚡ **Fast & Lightweight** — Pure HTML/CSS/JS with zero bloat
- 🔌 **API Integration** — Connects to the AI Showroom Backend REST API
- 🛍️ **AI Product Catalog** — Browse and filter AI tools, agents & automation products
- 📱 **Mobile-First** — Fully responsive across desktop, tablet, and mobile
- 🌐 **Deployed on Vercel** — Lightning-fast global CDN delivery
- 🎭 **Interactive Demos** — Embedded demos for featured AI products
- 🔍 **Search & Filter** — Find AI products by category, use case, or technology stack

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Optional: [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) VS Code extension

### Installation

```bash
# Clone the repository
git clone https://github.com/salikahmed595/ai-showroom-frontend.git

# Navigate to project directory
cd ai-showroom-frontend

# Open with Live Server or directly in browser
open index.html
```

### Configuration

Update the API base URL in your JavaScript config to point to the backend:

```javascript
const API_BASE_URL = 'https://your-backend-url.com/api';
```
